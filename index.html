Getting a token
  1. Go to GitHub → Settings → Developer settings → Personal access tokens.
  2. Generate a new token (fine-grained is fine) scoped to just this repository.
  3. Grant it "Contents: Read and write" access.
  4. Copy the token and paste it here. It's stored only in this browser and used only to write a dedicated tminus-* branch on this repo — never main, never any other repo.

T-Minus defaults to naming convention Index.html at the root or inside /public, /dist, /build), then App.tsx at the root or inside /src. Name your entry file to match one of these so it resolves properly or choose the correct live file.
