Getting a token
  1. On GitHub, click your profile photo in the top-right corner, then click Settings.
  2. Scroll all the way to the bottom of the left sidebar and click Developer settings.
  3. Click Personal access tokens, then Fine-grained tokens, then the green Generate new token button. (Direct link: github.com/settings/tokens)
  4. Give it any name (e.g. "T-Minus") and set an expiration date.
  5. Under Repository access, choose Only select repositories and pick this one.
  6. Under Permissions, click + Add permissions, search for Contents, and select it.
  7. It'll be added with a dropdown next to it — set that to Read and write.
  8. Scroll down and click Generate token.
  9. GitHub shows the token only once — copy it right away, then come back and paste it into the field here.

Without it, your comments only exist in your own browser — nobody else on the review will ever see them.
